# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project is

A personal learning project on calculus; the deliverables are Jupyter notebooks in `coursera/`, `hypersklill/`
(the folder name is spelled this way) and `my_learning/`. `GUIDELINES.md` is the authoritative spec for how
every notebook must be written. Read it before creating or editing a notebook.

## Concept sheets

Most notebooks embed a one-page concept sheet (`<folder>/img/<name>.png`, 1600x1000) in a
"### The whole story on one page" markdown cell right before the Exercises (or before the Summary/Conclusion
when there are none). The sheets are generated by `scripts/make_*_concept_images.py` (one script per course
folder, named after it), sharing one look via `scripts/viz_style.py`. Each script rebuilds the notebook's data
with the same seeds and asserts its numbers against the notebook's outputs, so:

- if you change a notebook's data, parameters or the numbers/claims a sheet shows, rerun its script
  (e.g. `/opt/anaconda3/bin/python scripts/make_coursera_02_gradients_concept_images.py`) and fix any failing assert;
- a new notebook gets a sheet too when it makes sense: add a sheet function to its folder's script and the embed cell.

## Environment

Two Python environments touch the notebooks: Anaconda (`/opt/anaconda3/bin/python`, numpy 1.x) and the
PyCharm virtualenv (numpy 2.x). Write numpy code that works in both; avoid APIs removed in numpy 2.0
(`np.trapz`, `np.in1d`, `np.row_stack`).
